# Runtime dynamic dispatch for Any and Union types (v3)

This change adds runtime type dispatch for arithmetic, comparison, truthiness, str/print, len, iteration, indexing, membership, and unary operators when the compiler encounters Any or Union operands. An 806-line `operator/dynamic.go` implements all host functions using NaN-boxed `Boxed.Kind()` dispatch. The v2 issues are both fixed correctly: `DynStr`/`DynPrint` now use a new `hostabi.FormatDynamic` that recursively probes arrays and maps at runtime with cycle detection, and `intBinary` routes negative exponents to `math.Pow` returning a float. All 40+ tests pass including the new v2-fix regression tests.

Watch for: no blocking concerns remain. The `isDynamicType` function in `compiler/check_expr.go` duplicates `types.IsDynamic` logic inline rather than delegating (possible, minor style issue not worth blocking).

**Verdict**: APPROVED

## High-level view

The container-formatting fix adds `hostabi.FormatDynamic`, which recursively probes ref values through `dynamicArrayElems` and `dynamicMapEntries` with cycle detection, producing correct Python representations for nested containers.

The negative-exponent fix routes `intBinary` to `math.Pow` when `right < 0`, returning a float as Python does.
